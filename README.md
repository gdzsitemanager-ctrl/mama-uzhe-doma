# МАМА УЖЕ ДОМА — survival horror

Оригинальный браузерный хоррор на HTML/CSS/JavaScript, который можно запускать на ПК и телефоне.

## Запуск
Откройте `index.html` в современном браузере. Звук включается после нажатия «Начать кошмар» (ограничение браузеров на автозапуск аудио).

## Управление
- WASD или стрелки — движение
- E или пробел — взаимодействие
- На телефоне — экранные кнопки

## Игровая цель
Найти три предмета и выбраться из дома, пока не истекло время. Есть процедурные звуковые эффекты, тревожные события и скример.

## Публикация
Включите GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
Затем сайт станет доступен по адресу https://gdzsitemanager-ctrl.github.io/mama-uzhe-doma/

Это оригинальный прототип; внешний сервис, сервер и скачивание чужих игровых файлов не требуются.
